================================================================================
DECISION CLASSIFICATIONS IMPLEMENTED
================================================================================

APPROVED - When:
✓ Risk Score < 30
✓ Credit Score ≥ 700
✓ DTI Ratio ≤ 0.43
✓ No critical anomalies
✓ Income stability high

REJECTED - When:
✓ Risk Score > 70
✓ Credit Score < 600
✓ DTI Ratio > 0.60
✓ Multiple anomalies
✓ Employment unstable

REVIEW - All other cases:
✓ Requires manual assessment
✓ Mixed signals
✓ Edge cases
